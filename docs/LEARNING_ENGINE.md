> "Não treinamos métricas.

# Visão

O Learning Engine representa o coração do TFT Insight.

Seu objetivo não é calcular estatísticas nem produzir respostas por IA.

Seu objetivo é transformar conhecimento especializado sobre Teamfight Tactics
em um sistema capaz de ensinar jogadores a evoluir de forma estruturada.

Enquanto o Performance Engine responde:

> Como o jogador está?

O Learning Engine responde:

> O que o jogador precisa aprender agora?

Essa diferença define toda a arquitetura do projeto.

---

# Filosofia

O TFT Insight foi concebido como um Sistema Especialista.

Modelos de linguagem podem explicar conceitos em linguagem natural,
mas nunca serão responsáveis pelas decisões pedagógicas.

Toda decisão sobre:

- o que ensinar;
- quando ensinar;
- como ensinar;
- quando avançar para o próximo conteúdo;

é responsabilidade exclusiva do Learning Engine.

A IA possui apenas uma função:

Transformar conhecimento estruturado em uma conversa natural.

---

# Objetivo do projeto

O objetivo do TFT Insight não é aumentar um Score.

O objetivo é desenvolver jogadores.

O Score é apenas uma consequência.

O sistema mede evolução através de competências.

Competências são desenvolvidas através de hábitos.

Hábitos geram decisões melhores.

Decisões melhores geram resultados.

Resultados melhores aumentam o Score.

O fluxo sempre acontece nessa ordem.

Nunca ao contrário.

---

# Princípios Fundamentais

## Princípio 1

Resultados não são treinados.

Resultados são consequências.

Errado:

> Melhore seu dano.

Correto:

> Aprenda a estabilizar seu tabuleiro antes do Stage 4.

O dano aumentará naturalmente.

---

## Princípio 2

Toda missão deve ensinar um comportamento observável.

Nunca um resultado.

Uma missão correta:

✔ Faça scout antes de cada combate.

Uma missão incorreta:

✖ Aumente sua média de dano.

---

## Princípio 3

O jogador aprende apenas uma competência por vez.

Aprender TFT significa reduzir carga cognitiva.

Quanto menor o número de objetivos simultâneos,
maior será a retenção do aprendizado.

---

## Princípio 4

O jogador precisa sentir progresso.

O sistema deve demonstrar claramente:

- o que foi aprendido;
- o que ainda falta aprender;
- qual será o próximo objetivo.

---

## Princípio 5

Toda Skill possui pré-requisitos.

Nenhuma Skill existe isoladamente.

Economia influencia Leveling.

Leveling influencia Board Strength.

Board Strength influencia Dano.

Dano influencia Eliminações.

Eliminações influenciam Colocação.

---

# Domínio de Aprendizagem

O Learning Engine utiliza sete conceitos fundamentais.

Esses conceitos formam toda a arquitetura do sistema.

## Skill

Representa uma competência.

Exemplos:

- Economia
- Leveling
- Scout
- Posicionamento
- Flexibilidade

Uma Skill não representa números.

Ela representa capacidade de tomada de decisão.

---

## Habit

Representa um comportamento repetitivo.

Exemplo:

Antes de cada rodada:

> Meu board vence a próxima luta?

Esse hábito fortalece diversas Skills simultaneamente.

---

## Lesson

Uma Lesson explica um conceito.

Ela responde:

Por quê?

Exemplo:

Por que subir para o nível 8?

---

## Mission

Uma Mission pratica uma Skill.

Ela responde:

Faça isso durante as próximas cinco partidas.

---

## Coach Session

Uma Coach Session representa uma sessão completa de treinamento.

Ela contém:

- diagnóstico;
- objetivo;
- plano;
- missão;
- checklist;
- conceitos;
- evolução esperada.

---

## Progress

Representa quanto uma Skill evoluiu.

Não mede apenas Score.

Mede domínio.

---

## Learning Path

Representa a ordem correta de aprendizado.

Nem toda Skill está disponível desde o início.

---

# Como uma Skill é considerada dominada

Uma Skill nunca será considerada dominada
apenas porque o jogador obteve um bom resultado.

Ela deverá apresentar consistência.

Critérios possíveis:

- estabilidade;
- repetição;
- evolução sustentada;
- redução de erros comuns.

---

# Papel do Coach

O Coach não toma decisões.

O Coach interpreta.

Ele recebe:

- Performance;
- Learning Plan;
- Coach Session.

E transforma essas informações em uma comunicação natural.

---

# Papel da IA

A IA nunca decide.

Ela nunca define prioridades.

Ela nunca cria Missões.

Ela nunca altera o Learning Path.

Sua responsabilidade é exclusivamente textual.

Ela transforma conhecimento estruturado
em uma conversa semelhante à de um treinador.
