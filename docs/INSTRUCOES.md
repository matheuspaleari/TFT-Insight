# Protótipo de popup flutuante

Substitua:

- `app/streamlit_app.py`
- `styles/home.css`

Execute:

```powershell
python -m streamlit run app/streamlit_app.py
```

Agora o botão **Ver detalhes** abre um painel fixo no canto inferior direito, mantendo a Home visível ao fundo.

Observação: este é um popup dentro da janela do navegador. Para ficar sobre o jogo como MetaTFT/OP.GG, a etapa futura será empacotar a interface em uma janela desktop/overlay.
