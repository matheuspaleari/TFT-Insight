# Product Intelligence — v0.6.0-alpha.1

Esta release implementa três experiências:

## Explainability Premium

Transforma os dados já expostos pela API em:

- Recommendation
- Confidence narrative
- Pre-game attention
- Win condition
- Evidence
- Decision path

Não cria fatos novos. Apenas organiza o que o contrato público fornece.

## Benchmark Insights

Traduz percentis em:

- Overall reading
- Maior diferencial
- Maior oportunidade

Os insights são derivados exclusivamente das comparações retornadas
pelo Benchmark Intelligence.

## Executive Dashboard

Nova página para demonstração e leitura rápida.

Consolida:

- Score
- Top 4
- Confidence
- Expected Placement
- Benchmark Percentile
- Strength
- Opportunity
- Pre-game attention
- Win condition

Technical Details permanece recolhido.
